# Швидкий старт StyleAI

## Запуск проекту

1. **Встановіть залежності:**
```bash
pip install -r requirements.txt
```

2. **Застосуйте міграції:**
```bash
python manage.py migrate
```

3. **Створіть суперкористувача (опціонально):**
```bash
python manage.py createsuperuser
```

4. **Завантажте тестові дані:**
```bash
python manage.py create_sample_data
```

5. **Запустіть сервер:**
```bash
python manage.py runserver
```

6. **Відкрийте в браузері:**
- Головна сторінка: http://127.0.0.1:8000/
- Адмін-панель: http://127.0.0.1:8000/admin/

## Основні функції

✅ **Підбір зачіски за допомогою AI**
- Завантажте фото на сторінці "Підбір зачіски"
- AI проаналізує форму обличчя та підбере підходящі зачіски
- Перегляньте рекомендації з рівнем впевненості

✅ **Пошук майстрів**
- Шукайте майстрів за стилем, містом або ім'ям
- Переглядайте профілі майстрів з рейтингами та відгуками
- Фільтруйте за популярними стилями

✅ **Система відгуків**
- Переглядайте відгуки користувачів
- Рейтинги та коментарі про майстрів

## Структура проекту

- `styleai/` - Головний додаток (головна, підбір зачіски, про нас)
- `masters/` - Додаток для майстрів (пошук, профілі)
- `hairstyles/` - Додаток для зачісок (каталог стилів)

## Примітки

- AI аналіз зараз симулюється (генерує випадкові рекомендації)
- Для реального використання потрібна інтеграція з AI API (наприклад, TensorFlow, PyTorch або зовнішній сервіс)
- Фото майстрів та зачісок можна додати через адмін-панель
