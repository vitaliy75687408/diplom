# StyleAI - Система підбору зачісок за допомогою AI

Веб-сайт для підбору зачісок за допомогою штучного інтелекту та пошуку майстрів/барберів.

## Функціонал

- 🎨 Підбір зачіски за допомогою AI (завантаження фото та аналіз)
- 👨‍💼 Пошук майстрів за стилем та локацією
- ⭐ Система відгуків та рейтингів
- 📱 Сучасний адаптивний дизайн

## Встановлення

1. Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Застосуйте міграції:
```bash
python manage.py migrate
```

3. Створіть суперкористувача:
```bash
python manage.py createsuperuser
```

4. Завантажте тестові дані:
```bash
python manage.py create_sample_data
```

5. Запустіть сервер:
```bash
python manage.py runserver
```

## Структура проекту

- `styleai/` - Головний додаток (головна сторінка, підбір зачіски)
- `masters/` - Додаток для роботи з майстрами
- `hairstyles/` - Додаток для роботи з зачісками

## Використання

1. Відкрийте http://127.0.0.1:8000/ в браузері
2. Натисніть "Підібрати зачіску" та завантажте фото
3. Перегляньте рекомендації AI
4. Знайдіть майстра за обраним стилем

## Адмін-панель

Доступ до адмін-панелі: http://127.0.0.1:8000/admin/

## Примітки

- AI аналіз зараз симулюється (для реального використання потрібна інтеграція з AI API)
- Для завантаження фото майстрів та зачісок використовуйте адмін-панель
